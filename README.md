# 🎫 IT Support & Helpdesk Simulations

Welcome to my IT Support Portfolio. 

This repository is dedicated to documenting real-world Helpdesk and IT Support scenarios. I believe the best way to prove technical competence is not just through certificates, but through **documented proof of troubleshooting**.

## 📌 Purpose
In a corporate environment, IT Support is about resolving tickets efficiently, documenting the fix, and communicating clearly. I use this repository to simulate Tier 1 and Tier 2 support tickets, showing my step-by-step methodology for resolving issues across Linux, Windows, Networking, and Cloud environments.

## 🛠️ Core Skills Demonstrated in this Repo

*   **Operating Systems:** Linux (Debian/Ubuntu), Windows
*   **Networking:** SSH, TCP/IP, Port Scanning (`netcat`), Firewalls (AWS Security Groups)
*   **Cloud Infrastructure:** Amazon Web Services (EC2)
*   **Documentation:** Markdown, technical writing, and visual proof (screenshots).

## 🚀 How to Read These Tickets
Every ticket in this repository follows a standard ITIL-style format:
1.  **Issue Summary:** What is the problem?
2.  **Environment:** What tools and systems are involved?
3.  **Troubleshooting & Resolution:** The step-by-step fix.
4.  **Proof of Work:** Screenshots of the terminal and the final result.
5.  **Key Learnings:** What I took away from the scenario.
